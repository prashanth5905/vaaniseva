# VaaniSeva

VaaniSeva is a voice-first multilingual AI assistant designed to make
digital government services more accessible.

Users can interact through text or voice in English or Telugu, receive
responses in both text and audio, retrieve existing certificates through
a secure mock identity-verification workflow, and obtain information
about government services through a RAG-based knowledge assistant.

## V1 Goals

- English and Telugu conversations
- Text and voice input
- Text and audio responses
- Government-service information using RAG
- Mock citizen identity verification
- OTP-based authentication
- Secure certificate retrieval
- WhatsApp-like web interface

> VaaniSeva is a demonstration project and does not connect to Aadhaar
> or real government citizen databases.
